This tool is based on NCrafters palette extender tool and works the same. [Original Tool here.](https://github.com/ninaforce13/CustomPaletteExtender)
The main differences here are mainly how the monsters are patched and that 30 colors are available to edit.
Files have been provided to also handle incompatibilities with certain mods.
I use this tool for [my own mod on Steam Workshop.](https://steamcommunity.com/sharedfiles/filedetails/?id=3490023576)
